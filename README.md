# Freedom Through Retainers

Static site for freedomthroughretainers.com. No build step.

- `index.html`: the offer page. Settings at the bottom of the file: `VIMEO_ID`, `FORM_ENDPOINT`.
- A/B: `?v=a` (VSL + form only) or `?v=b` (full page). Visitors are split 50/50 by cookie `ftr_v`.
- `thanks.html`, `privacy.html`, `terms.html`: supporting pages (clean URLs via vercel.json).
